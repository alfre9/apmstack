# APMstack

Active domain: northdock
Example: yes

This folder is a PM home: everything APMstack knows, as plain markdown you can read and edit.
This one is the bundled sample (Northdock, a fictional freight-invoicing company). Run `/pm-setup` to create your own.

- `domains/<name>/`: one domain pack per product area
- `connectors.md`: which connected tools APMstack may use, and how (created by `/pm-setup`)
